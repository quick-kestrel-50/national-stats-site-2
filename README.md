# World Atlas of Nations

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/best-national-statistics-site-20261126-0539)

**THE WORLD IN NUMBERS — Every nation, every number, one table.**

A national statistics site: 24 countries × 6 indicators, all World Bank
World Development Indicators 2023, in a dense sortable table, with Top-10
charts, a page per country (with a head-to-head comparison), a page per
indicator with a full ranking, and a sources &amp; method page.

- Search, region filter and column sorting — state lives in the URL hash,
  so any view is a shareable link.
- Every figure carries its source and year. No figure is estimated.
- Static files only, no network, no build step. Open `app/index.html`
  or serve `app/` with any static server.
